# 素材生成指令

> 这份文档是**作业清单**：每个动作一张图、一段完整 prompt，复制即用。
> 不需要自己拼接，也不需要理解管线。

## 怎么用

1. **一个动作一张图，共 6 张。** 不要把多个动作塞进同一张——格子会变小、角色会走形、一处失败就得整张重来。
2. 每张图粘**对应那一节里的完整 prompt**，从 `Create a 2x2` 开始到 `ground shadows.` 结束。
3. **先生成 `idle`**。它定下画风，其余动作都以它为基准。
4. 生成后按文末的自查表过一遍，不过就重生成。
5. 图放哪都行，把路径告诉我。

生成顺序建议：`idle` → `climb` → `sit` → `wave` →（可选）`fall` → `sleep`。

---

## 通用规格（所有图都一样）

| 项 | 值 |
| --- | --- |
| 画布 | 1024 × 1024 |
| 网格 | 2 × 2，四等格，**不画分割线** |
| 背景 | 纯洋红 `#FF00FF`，均匀无渐变 |
| 每格 | 全身完整，占格子高度约 70%，脚靠近格子底部 |
| 风格 | 扁平 2D 矢量，粗棕描边，无阴影无渐变 |
| 禁止 | 文字、水印、箭头、地面投影、动作线 |

**为什么是洋红不是透明**：模型说「透明背景」时经常画一个棋盘格上去，而且输出没有 alpha 通道。洋红能被精确抠掉。

---

## 角色描述（已内嵌在每个 prompt 里）

以下所有 prompt 都包含同一段角色描述，不要改动它，否则各动作之间会走形：

```
A chubby egg-shaped white bird mascot, head and body merged into one rounded
shape with no visible neck. Features:
- thick dark warm-brown outline (#a9634f) around the entire body
- pure white body, no shading, no gradient
- a small oval yellow beak centered on the face
- happy curved eyes with visible eyelids, cheerful expression
- three short pink diagonal lines on each cheek as blush
- small red swim trunks around the hips
- short rounded arms, small dark brown feet
Flat 2D vector cartoon. No 3D, no shading, no highlights, no texture.
```

## 1 / idle —— 站姿呼吸（4 帧，最高优先级）

定画风的一张。四帧差异要非常小，只有呼吸的起伏，脚完全不动。

```
Create a 2x2 sprite sheet on a flat solid magenta background (#FF00FF).

CANVAS
1024x1024, divided into four equal cells (2 columns, 2 rows).
Do NOT draw grid lines, borders, dividers or background panels between cells.

CHARACTER — must be exactly the same character in all four cells:
A chubby egg-shaped white bird mascot, head and body merged into one rounded
shape with no visible neck. Features:
- thick dark warm-brown outline (#a9634f) around the entire body
- pure white body, no shading, no gradient
- a small oval yellow beak centered on the face
- happy curved eyes with visible eyelids, cheerful expression
- three short pink diagonal lines on each cheek as blush
- small red swim trunks around the hips
- short rounded arms, small dark brown feet
Flat 2D vector cartoon. No 3D, no shading, no highlights, no texture.

BACKGROUND
One uniform flat solid magenta (#FF00FF) across the whole canvas.
No checkerboard, no transparency grid, no gradient, no vignette, no glow.

POSES
A calm standing idle, four frames of a subtle breathing loop, facing the viewer.
1. top-left:     standing upright, arms relaxed at the sides, neutral resting pose
2. top-right:    the same standing pose, body very slightly raised, as if breathing in
3. bottom-left:  the same pose, body very slightly lowered, as if breathing out
4. bottom-right: the same pose, back to neutral

Keep the differences VERY subtle. This is breathing, not walking.
The feet must stay in exactly the same position in all four cells.

HARD REQUIREMENTS
- Every cell must show a visibly DIFFERENT pose, but only by a small amount.
- The character must look identical across all four cells: same size, same
  proportions, same face, same outline weight, same colors.
- Each cell shows the FULL body, head to feet, nothing cropped, nothing
  touching the cell edges. Character fills about 70% of each cell's height,
  feet near the bottom of that cell.
- Keep each character inside its own cell.

DO NOT INCLUDE
Any text, letters, numbers, labels, arrows, watermark, signature, logo,
motion lines, or ground shadows.
```

## 不用生成的动作

这四个用程序化变换就够，看不出破绽：

| 动作 | 现有做法 | 为什么够用 |
| --- | --- | --- |
| `peek` 探头 | 整体前倾 5° | 只是探一下，不需要肢体动作 |
| `jump` 跳跃 | 竖向压缩 → 拉伸 → 回弹 | 弹跳感来自挤压，不来自腿 |
| `land` 落地 | 压扁 → 过冲 → 归位 | 同上 |
| `drag` 被拎起 | 竖向拉长 + 左右摆 | 悬空时腿本来就松垮 |

## 生成后的自查

拿给我之前，每张都过一遍：

- [ ] 四个格子里是**同一个角色**（胖瘦、脸、配色、描边粗细一致）
- [ ] 四个姿势**明显不同**，符合这一节描述的差异
- [ ] 每格角色**完整**，手脚没被格子边缘切掉
- [ ] 背景是**均匀洋红**，不是棋盘格、不是渐变、不是白底
- [ ] 没有文字、水印、编号、箭头、地面阴影

任何一条不过，重生成比后期修补便宜。

## 交付

| 动作 | 文件名随意，给我路径即可 |
| --- | --- |
| idle | `idle.png` |
| climb | `climb.png` |
| sit | `sit.png` |
| wave | `wave.png` |
| fall | `fall.png`（可选） |
| sleep | `sleep.png`（可选） |

我接手后每张跑同一条流程：

1. 切成 4 格
2. 洋红抠底 + 反解前景色（去紫边）
3. 求 alpha 包围盒，按**脚底**对齐
4. 按各帧高度中位数统一缩放，贴进 324×324，锚点 (162, 300)
5. 拼成水平条 webp
6. 更新 `manifest.json` 的 clip
7. 跑 QA 检查脚底漂移
8. 构建 → 浏览器实测 → 同步 → 部署

`walk` 已经用这套流程跑通了：4 帧、脚底漂移 0px、抠图无紫边、62KB。
